Core business workflows

Order → receipt → invoice

frmOrder uses dsOrder/dsOrderSearch and order stored procedures. frmOrderReceive records receipts. frmSaleInvoice renders docSaleInvoice or docSaleDelivered from dsSaleInvoice.

Purchase → stock

frmPurchase uses purchase detail/search datasets and spCreate/Update/DeletePurchase. Purchase detail reporting flows through dsDetailPurchase → docDetailPurchase.

Branch / HBC stock

HBC challans, stock-in/out, reverse and rectification live across Inventory and Stock. Ledger reporting uses dsStockLedger → docStockLedger.

Manufacturing

Raw items and stock-in feed manufacturing/finished-goods screens. Separate typed datasets and reports track raw branch goods, finished output and item stock.

Daily financial picture

frmDailyReport combines sales, receipts, expenses, PR invoices, internal/manufacturing stock and HBC activity into docDailyReport with totals passed as Crystal parameters.

Security / permissions

Users belong to groups; group rights map user forms. frmCenter also changes menu visibility based on setup/software type, with extra frmSecurity prompts around sensitive actions.

Entity Framework & database surface

DbContext

DBModel/InventortModel.Context.cs defines InventoryEntities(string connectionString) and calls base("name=" + connectionString). It is database-first; OnModelCreating rejects Code First.

Connection selection

Named EF connections represent software/branch databases. User settings also store connection name/string, server, branch, invoice code and user name. Do not put new passwords in these settings or source files.

Build & operational notes

Build

  • Open Ncsln/Ncsln.sln.
  • Target .NET Framework 4.8.1.
  • Release is x86; match the Crystal runtime bitness.
  • Restore EntityFramework 6.0 package references.

Run

  • Startup object is Program.Main.
  • Initial screen is Forms.frmLogin.
  • SQL Server connectivity and a valid named connection are prerequisites.
  • Crystal Reports runtime 13.x is required for preview/print.

Setup projects

The repository includes NiceSolutionsSetup and PrerequisitesInstaller. Review their bundled runtimes and connection/config transforms before shipping.

Supporting projects

CControl provides a numeric textbox. Library/Core/CoreControl is a separate library/solution. The main application also includes barcode Code 128 helpers.

Maintenance risks & memory clues

Secrets

Plaintext remote DB credentials are committed in app.config and connection text files exist at repository root. Treat as compromised; rotate and externalize.

Naming drift

Names include historical misspellings such as InventortModel, dsIntenalStock, dsItemDetialStock, dsStockReveseReport, docMFinsihGoods, and Expance. Avoid “fixing” names without updating bindings.

Historical artifacts

docSaleInvoice-bak2102.14.rpt, backup stored procedures, Debug ZIPs and compiled binaries are present. Confirm whether they are deployable, reference-only, or removable.

Mixed data access

Forms combine EF entities/stored procedures with manually filled typed datasets. When debugging, follow the form event → query → DataTable fill → report SetDataSource chain.

Menu visibility

frmCenter hides/shows modules according to setup/software type and contains commented-out launch paths. A form existing on disk does not guarantee it is reachable in every deployment.

Report reuse

docTrend is reused by trend, negative-stock and user-log screens; docCashBankingPayment is reused by banking/cash/vendor detail paths. Check dataset compatibility before modifying shared layouts.
